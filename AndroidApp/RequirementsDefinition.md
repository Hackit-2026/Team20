# アプリ総合要件定義書 (Requirements Definition - 最新統合確定版)

本ドキュメントは、アプリ「ヤニモグラ」の全機能仕様・計算公式・画面遷移・2段階ペナルティ・目標調整2モード仕様をまとめた仕様書です。
※本ドキュメントでは「AI」「人工知能」という表現を完全に排除しています。

---

## 1. アプリ概要 & コアコンセプト
- **アプリ名**: **ヤニモグラ (YANI-GOTCHI)**
- **コンセプト**: 「タバコを促進してキャラを育てる反面教師育成 ＆ 禁煙・減煙支援アプリ」

---

## 2. 📱 画面構成 ＆ ナビゲーション分離仕様
- **メイン画面 (`HomeScreen.kt`)**: 本日の日付 (M/d)、本日の申告状況、本数入力 ＆ 保存ボタン、上部ナビゲーションボタン（「📊 履歴」「🎯 減煙設定」「🛠️ デバッグ」）。
  - **マイナスボタン視覚エフェクト**: 「−」ボタンをタップした際、画面中央に「✨ 減煙成功！ (-1本)」というダイナミックグリーン発光＆アニメーションポップアップを表示。
  - **重度ペナルティ警告壁紙**: 直近1週間の合計吸った本数が **2本以上** の場合、スマホ本体の端末壁紙およびアプリ背景が警告テーマ壁紙に自動変更される。
- **履歴画面 (`HistoryScreen.kt`)**: 過去の全申告ログ一覧 ＋ 最上部に1週間(7日) ＆ 1ヶ月(30日)の切り替え棒グラフ (`SmokingHistoryChart`) を表示。
- **減煙設定画面 (`GoalSettingScreen.kt`)**: 重み付き平均分析 ＋ **目標達成が厳しい場合の2つの目標調整モード選択（Mode 1 ＆ Mode 2）**。
- **デバッグ画面 (`DebugScreen.kt`)**: 指定日付登録・30日デモデータ挿入・通知時間設定・全リセット。
- **🔙 システム戻るボタン / 戻るジェスチャーのハンドリング**: サブ画面（履歴・減煙設定・デバッグ）に滞在中、スマホ端末のシステム戻るボタンまたはジェスチャーを実行した際、自動的にメイン画面 (`HomeScreen`) へ手戻り遷移する。

## 3. 喫煙量分析 ＆ 段階的減煙システム【最新確定要件】

### 3-1. 目標達成が厳しければ選べる2つのモード
ユーザーが目標達成が困難な場合、減煙設定画面 (`GoalSettingScreen`) にて状況に応じた 2 つの調整モードを自由に選択・適用可能。

1. **🌱 Mode 1: 段階的減煙モード (`MODE_1_GRADUAL`)**:
   - **計算公式**:
     $$\text{今日の目標} = \text{floor}\left(\frac{\text{今までの1週間の平均値}}{1.5}\right)$$
   - 小数点以下切り捨て (`floor`) 処理を実施。
2. **🚫 Mode 2: 完全禁煙固定モード (`MODE_2_ZERO`)**:
   - **計算公式**:
     $$\text{今日の目標} = 0$$
   - 今日の目標本数を常に `0` 本に固定維持する。

### 3-2. 本数入力の初期値設定（過去4週間の最大値の2/3）
- **初期値計算公式**:
  $$\text{本日の入力初期値} = \text{floor}\left(\text{過去4週間 (過去28日間) の日別吸った本数の最大値} \times \frac{2}{3}\right)$$

### 3-3. 先日から1週間前までのタバコの吸った量の重みづけ (Weighted Average)
- **計算ロジック**: 直近7日間（昨日〜7日前）の吸った本数に対し、新しい日ほど大きな重み（昨日=1.0, 2日前=0.85, 3日前=0.7, 4日前=0.55, 5日前=0.4, 6日前=0.25, 7日前=0.1）を乗算して「重み付き平均本数」を算出する。

## 4. 🚨 2段階ペナルティ ＆ 重度ペナルティ警告壁紙

### 4-1. 重み付きペナルティ評価値の計算公式
- **計算式**:
  $$\text{PenaltyValue} = (\text{前日} \times 2.0) + (\text{2日前} \times 1.5) + (\text{3日前} \times 1.2) + (\text{4日前} \times 1.0) + (\text{5日前} \times 0.8) + (\text{6日前} \times 0.5)$$

### 4-2. 2段階のペナルティ挙動 ＆ 警告壁紙
1. **軽度ペナルティ ($2.0 \le \text{PenaltyValue} < 5.0$)**: 他アプリ（Chrome等）を開いた際、画面上に「⚠ ペナルティ注意」メッセージオーバーレイを表示（「閉じる」で即時解錠）。
2. **重度ペナルティ ($\text{PenaltyValue} \ge 5.0$ または 1週間合計2本以上)**:
   - **スマホ端末システム壁紙自動変更**: Android の `WallpaperManager` 経由でスマホ本体の壁紙を「🚨 重度ペナルティ危険警告壁紙」に変更。
   - **60秒間完全回避不能ロック**: 他アプリを開いた際および自アプリ内で「もっと禁煙してください！」と表示し、60秒間は操作をロック。

## 5. デバッグ ＆ 運用機能仕様
- 過去30日間のデモデータ一括投入
- 何月何日（`YYYY-MM-DD`）を指定してタバコデータを入れる機能
- リマインド通知時刻（時・分）の設定
- 全データ完全初期化リセット機能
