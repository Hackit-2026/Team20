# 📱 Android開発AI専用 指示書 (Android App AI Prompt)

このドキュメントは、AndroidApp (Kotlin / Jetpack Compose) の開発を担当するAIエージェント向けの**開発指示書**です。以下の要件および設計に従ってコードを生成・リファクタリングしてください。

---

## 🎯 アプリ概要
- **アプリ名**: **ヤニモグラ (YANI-GOTCHI)**
- **アーキテクチャ**: Android Jetpack Compose + MVVM (ViewModel, Repository)
- **バックエンド通信**: Python (FastAPI) サーバー API (`http://localhost:8000/api/`)

---

## 📋 画面別・ロジック仕様要件

### 1. ポイント計算ロジック (`data/Repo.kt`, `logic/Stage.kt`)
- **ポイント範囲**: 0pt 〜 200pt (`0 <= points <= 200`)
- **1日のポイント変化公式**: **`ポイント変化量 = (吸った本数 - 1) pt`**
  - `0本`: `-1 pt` (禁断症状演出セリフ発火)
  - `1本`: `0 pt` (±0)
  - `2本以上`: `+(本数 - 1) pt`
- **ビジュアル進化**: `(points / 10).coerceIn(0, 20)` で全21段階 (0~20) のキャラクター画像・絵文字・セリフ・動的背景色を更新。

### 2. 初期設定画面 (`ui/OnboardingScreen.kt`)
- チャレンジ期間選択（3日/7日/14日/30日）
- **目標本数ピッカーの初期値**: **`10本`**

### 3. メイン画面 (`ui/HomeScreen.kt`)
- **中央画像**: キャラクター表示を**大きく拡大表示**。
- **ボタン配置**:
  - **左上ボタン**: 「履歴ボタン」（カレンダー/履歴画面へ遷移）
  - **右上ボタン**: 「デバッグボタン」（デバッグ画面へ遷移）
- **本数カウントと確定ボタン**:
  - 表示本数の初期値: オンボーディングで設定された**「目標本数 (10本など)」**。
  - `+` / `-` ボタンで調整。
  - **確定保存ボタン**: **1日に1回のみクリック可能**（同日の重復保存をフラグで制御）。
- **タイムライン導線**: マルチAIタイムライン画面へ遷移するボタン。

### 4. 履歴画面 (`ui/CalendarScreen.kt`)
- メイン画面の**「左上ボタン」**から遷移。
- 吸った本数の推移を **「1週間分グラフ」** および **「1ヶ月分グラフ」** で切替表示。

### 5. デバッグ画面 (`ui/DebugScreen.kt`)
- メイン画面の**「右上ボタン」**から遷移。
- **リザルト画面へのアクセス**: **`ResultScreen.kt` への遷移ボタンはデバッグ画面の中に配置**。
- **スマートウォッチ模擬テストボタン**: 実機なしをカバーする「動作・SpO2テスト発火ボタン」。
- 通知時間変更ダイアログ発火ボタン / デモデータ投入 / リセット機能。

### 6. マルチAIタイムライン画面 (`ui/CommunityFeedScreen.kt`)
- Pythonサーバー (`GET http://10.0.2.2:8000/api/feed`) からタイムライン投稿を取得。
- アプリ専用NPCユーザーの投稿に対し、複数のAI（熱血AI🔥、ツンデレAI😳、ドクターAI👨‍⚕️、ヤニモグラ👹）が応援コメントを投稿する画面を描画。
